# 07_reopen: reopening the frozen profile (Step 5, A6)

**Purpose.** Only after the confirmatory result is locked, the frozen profile is reopened to ask whether
the effect differs for clips that belong to a retained configuration. The analysis is exploratory and
is reported as such. If the Step 4 result is null or only partly supported, nothing in this folder rescues,
qualifies, or softens it. 

## Files

run_reopen.py: corresponding to Technical Appendix A7.2  (illustrative code), Lock sequence

reopen_model.R: corresponding to Technical Appendix A6.1  (illustrative code). Model coded in R for better understanding statistical result. 

decision_rules.py: corresponding to Technical Appendix A6.2 (illustrative code). Another illustration of our decision rules
